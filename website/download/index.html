Install on Windows

For 64-bit Windows 10 or 11. The installer comes directly from the project's official GitHub Releases page.

Download for Windows (x64) VocabReader Windows x64 setup (.exe)

  1. Download and open the installer

    Save the .exe file, then double-click it from Downloads.

  2. If Windows shows a protection message

    Select More info, then select Run anyway to continue installing VocabReader.

  3. Finish setup

    Complete the installer and open VocabReader from the Start menu.

Why does Windows show a warning?

This Early Preview is not yet signed with a paid Windows publisher certificate, so SmartScreen may not recognize its publisher.

Do not disable SmartScreen or antivirus protection. You only need to allow this installer.

Install on macOS

Choose Apple silicon for M-series Macs. Choose Intel for older Intel-based Macs.

Not sure? Open Apple menu › About This Mac.

Download for Apple silicon VocabReader macOS Apple silicon (.dmg)
Download for Intel Mac VocabReader macOS Intel (.dmg)

  1. Open the disk image

    Double-click the .dmg file and drag VocabReader into Applications.

  2. Try opening VocabReader once

    Open it from Applications. If macOS blocks it, close the message.

  3. Find VocabReader in Privacy & Security

    Open System Settings › Privacy & Security, scroll to Security, select Force Open beside VocabReader, then confirm.

Why does macOS block the first launch?

This Early Preview is not yet signed and notarized with a paid Apple Developer ID, so macOS cannot verify its developer during the first launch.

You only need to allow VocabReader here. Keep Gatekeeper enabled; there is no need to change security settings for the whole Mac.

Apple Support: safely open apps

Install Codex to enable AI Tutor

This is a one-time setup. Choose your computer and follow the four steps below.

Already installed Codex? Start from step 3.

  1. Open PowerShell

    Press the Windows key, type PowerShell, then open Windows PowerShell. Keep this window open for the next two steps.

  2. Install Codex

    Select Copy install command, paste it into PowerShell, then press Enter and wait for it to finish.

    powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

  3. Sign in with ChatGPT

    Copy the login command, paste it into the same PowerShell window, and press Enter. Your browser will open for sign-in.

    codex login

  4. Return to VocabReader

    Complete the ChatGPT sign-in in your browser, then close and reopen VocabReader. AI Tutor is ready to use.

Already installed Codex? Start from step 3.

  1. Open Terminal

    Press Command and Space, type Terminal, then open it. Keep this window open for the next two steps.

  2. Install Codex

    Select Copy install command, paste it into Terminal, then press Return and wait for it to finish.

    curl -fsSL https://chatgpt.com/codex/install.sh | sh

  3. Sign in with ChatGPT

    Copy the login command, paste it into the same Terminal window, and press Return. Your browser will open for sign-in.

    codex login

  4. Return to VocabReader

    Complete the ChatGPT sign-in in your browser, then close and reopen VocabReader. AI Tutor is ready to use.

A ChatGPT plan or workspace with Codex access is required for AI Tutor.

Optional AI speech is separate and requires your own OpenAI API key only if enabled.
