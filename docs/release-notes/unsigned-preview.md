## VocabReader Early Preview

VocabReader is an EPUB language-learning reader powered by Codex. It connects focused
reading with contextual AI explanations, semantic learning items, FSRS spaced review,
retelling, listen-and-repeat practice, and integrated writing practice.

### Downloads

- **macOS Apple Silicon**: choose the `mac-arm64.dmg` file.
- **macOS Intel**: choose the `mac-x64.dmg` file.
- **Windows 64-bit**: choose the `windows-x64-setup.exe` file.

### Unsigned preview notice

These Early Preview installers are not yet code-signed or notarized. macOS Gatekeeper
and Windows SmartScreen may warn that the publisher cannot be verified. Only download
installers from this repository's official GitHub Releases page and verify the filename
before opening it.

VocabReader also requires a local Codex installation with a ChatGPT/Codex account that
can run `codex app-server`. AI voice features are optional and require your own OpenAI
API key.
