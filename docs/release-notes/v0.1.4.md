## VocabReader v0.1.4

This Early Preview release adds imaginative Memory tips to newly created
learning items, giving every new word or phrase a compact mental scene that is
easier to recall later.

### Highlights

- Generate a concrete Memory tip for every new AI-created word or phrase.
- Show Memory tips in a calm blue-violet panel that stands out from learning
  content while remaining less urgent than the red learning Note.
- Preview the Memory tip before submitting cards, then preserve it in the
  Learning Library where it can be edited or cleared manually.
- Keep Memory tips out of compact library lists and unanswered spaced-review
  questions so they do not reveal the recall cue too early.
- Safely migrate existing learning items with an empty Memory tip.

### Downloads

- **macOS Apple Silicon**: choose the `mac-arm64.dmg` file.
- **macOS Intel**: choose the `mac-x64.dmg` file.
- **Windows 64-bit**: choose the `windows-x64-setup.exe` file.

and are not notarized. macOS Gatekeeper and Windows SmartScreen may warn that

repository's official GitHub Releases page and verify the filename before
