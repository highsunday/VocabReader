# VocabReader v0.1.0 — Early Preview

The first downloadable VocabReader preview turns an EPUB chapter into one continuous
learning loop: read, mark what is difficult, ask Codex for contextual help, save semantic
learning items, review them with FSRS, and practise active recall through retelling,
listen-and-repeat, and integrated writing.

## Choose your installer

- **Apple Silicon Mac (M1 or newer):** `VocabReader-0.1.0-mac-arm64.dmg`
- **Intel Mac:** `VocabReader-0.1.0-mac-x64.dmg`
- **Windows 64-bit:** `VocabReader-0.1.0-windows-x64-setup.exe`

## Before installing

This is an unsigned Early Preview. The installers are not yet code-signed or notarized,
so macOS Gatekeeper or Windows SmartScreen may warn that the publisher cannot be
verified. Download only from the official `highsunday/VocabReader` GitHub Releases page.

VocabReader requires a local Codex installation and a ChatGPT/Codex account that can run
`codex app-server`. Core text AI features reuse that login. AI voice is optional and uses
an OpenAI API key supplied by the user.

## Highlights

- Local EPUB library with chapter hierarchy, reading progress, ranges, and annotations.
- Context-aware AI Tutor powered by Codex.
- Semantic learning library with CEFR metadata, examples, and FSRS scheduling.
- AI-generated spaced-review papers with user-confirmed ratings.
- Reading comprehension, retelling, listen-and-repeat, and integrated writing practice.
- Separate English, Japanese, and Traditional Chinese learning-language workspaces.
- Local-first learning data with manual backup and full restore.
