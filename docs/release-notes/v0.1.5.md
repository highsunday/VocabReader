## VocabReader v0.1.5

This Early Preview release makes learning cautions and Memory tips easier to
scan, and lets AI-assisted edits improve an existing item's Memory tip together
with its learning content.

### Highlights

- Place learning cautions and Memory tips directly after the Meaning section,
  before examples and other supporting sections.
- Present both cues as compact, clearly labeled callouts, with a stronger
  caution treatment and a calmer Memory tip treatment.
- Let `Edit with AI` update, preserve, or clear a Memory tip when the user's
  bounded editing request calls for it.
- Keep Memory tip changes inside the existing preview-and-Apply workflow, so AI
  output does not modify the Learning Library until the user confirms it.
- Improve spelling-oriented Memory tip guidance and preserve safe inline
  emphasis in previews and saved learning items.

### Downloads

- **macOS Apple Silicon**: choose the `mac-arm64.dmg` file.
- **macOS Intel**: choose the `mac-x64.dmg` file.
- **Windows 64-bit**: choose the `windows-x64-setup.exe` file.
