## VocabReader v0.1.3

This Early Preview release makes the installed application version visible in
Settings and keeps that value tied to the version embedded in each installer.

### Highlights

- Show the installed VocabReader version in the Settings footer.
- Add a visual learning-language picker and an isolated Korean workspace.
- Keep sentence-level annotations out of word and phrase learning-card drafts.
- Refresh the bilingual product and download guidance.

### Downloads

- **macOS Apple Silicon**: choose the `mac-arm64.dmg` file.
- **macOS Intel**: choose the `mac-x64.dmg` file.
- **Windows 64-bit**: choose the `windows-x64-setup.exe` file.

### Unsigned preview notice

These Early Preview installers use ad-hoc or unsigned application signatures and
are not notarized. macOS Gatekeeper and Windows SmartScreen may warn that the
publisher cannot be verified. Download installers only from this repository's
official GitHub Releases page and verify the filename before opening one.
