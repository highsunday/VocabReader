## VocabReader v0.1.9

This Early Preview release fixes Codex connection failures in the macOS app downloaded from GitHub.

### Fixes

- Find the native Codex CLI in the current ChatGPT app bundle layout.
- Add common CLI directories to the Codex child process PATH so a Homebrew npm installation can find Node when VocabReader starts from Finder.

Existing books, learning progress, and conversations are preserved.

### Downloads

- **macOS Apple Silicon**: choose the `mac-arm64.dmg` file.
- **macOS Intel**: choose the `mac-x64.dmg` file.
- **Windows 64-bit**: choose the `windows-x64-setup.exe` file.

### Unsigned preview notice

These Early Preview installers use ad-hoc or unsigned application signatures and are not notarized. macOS Gatekeeper and Windows SmartScreen may warn that the publisher cannot be verified. Download installers only from this repository's official GitHub Releases page and verify the filename before opening one.
