## VocabReader v0.1.7

This Early Preview release adds optional voice answers to Spaced Review and
makes voice setup clearer without introducing a stressful daily usage meter.

### Highlights

- Answer a Spaced Review prompt by speaking, then edit the recognized text
  before submitting the paper.
- Stop recording automatically after silence, after 8 seconds without speech,
  or at the 15-second hard limit.
- Upload audio only after recording stops, allow one transcription at a time,
  and never retry a failed transcription automatically.
- Recognize multilingual answers with OpenAI transcription while keeping
  review generation and grading on Codex.
- Rename AI Voice settings to Voice & Speech and explain which features use the
  separate OpenAI API key.
- Show an explicit Not saved state and a nearby Save & enable voice features
  action after an API key is entered.
- Remove the daily transcription progress meter and device-side 10-minute cap;
  per-recording safety limits remain in place.
