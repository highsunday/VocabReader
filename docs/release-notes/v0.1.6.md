## VocabReader v0.1.6

This Early Preview release makes reading-range boundaries more reliable and
hardens natural-language requests for creating learning cards.

### Highlights

- Expand AI reading context to the complete visual lines containing START and
  END, avoiding clipped boundary text without changing the displayed or saved
  range markers.
- Start the next reading segment after the previous END visual line, so the new
  START no longer appears on the preceding segment's final line.
- Preserve the original segment's approximate word-count target when advancing
  to the next visual line.
- Keep direct card-creation actions isolated from ordinary natural-language
  intent routing.
- Normalize safe string-form learning-item targets while retaining existing
  validation limits and object-shape contracts.
