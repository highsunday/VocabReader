## VocabReader v0.1.8

This Early Preview release fixes daily new-card limits and keeps existing
learning cards available when the new-card setting changes.

### Fixes

- Count a new card toward today's limit as soon as its first review is confirmed,
  regardless of its rating. Repeated practice does not count it again.
- Stop introducing new cards once the daily limit is reached, including cards
  that are still in their initial learning steps.
- Keep existing initial-learning cards available at their scheduled due times
  even when the daily new-card limit is set to zero.
- Keep cards started on earlier days separate from today's new-card allowance.
- Show learning cards, due reviews, and new cards separately in the next-paper
  summary, with clearer daily-progress and settings labels.
- Keep continuous listen-and-repeat controls visible when practicing long text.

Existing learning progress and review schedules are preserved. Today's new-card
count is reconstructed from existing review history; no manual data migration
is needed.

### Downloads

- **macOS Apple Silicon**: choose the `mac-arm64.dmg` file.
- **macOS Intel**: choose the `mac-x64.dmg` file.
- **Windows 64-bit**: choose the `windows-x64-setup.exe` file.

### Unsigned preview notice

These Early Preview installers use ad-hoc or unsigned application signatures
and are not notarized. macOS Gatekeeper and Windows SmartScreen may warn that
the publisher cannot be verified. Download installers only from this
repository's official GitHub Releases page and verify the filename before
opening one.
